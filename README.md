# מחולל לוחות שנה עבריים - Phase 1

## מה יש כרגע בשלב הזה
שלד פרויקט Next.js שיודע להציג **לוח חודשי** - גם עברי וגם לועזי - עם התאריך
המקביל הקטן מתחת לכל יום, וזיהוי חגים אוטומטי, בעזרת ספריית Hebcal.
בלי התחברות משתמשים, בלי אירועים אישיים, בלי תשלום - זה יגיע בפאזות הבאות.
המטרה של השלב הזה היא לוודא שה"מנוע" הבסיסי של הלוח עובד ונראה טוב, לפני
שבונים עליו את כל שאר המערכת.

בנוסף, קובץ `supabase/schema.sql` מכיל את **כל** מבנה בסיס הנתונים המתוכנן
לפרויקט המלא (טבלאות משתמשים, לוחות, אירועים, תמונות, יארצייטים, תשלומים) -
מוכן להרצה כשנגיע לשלב חיבור ה-Auth.

## איך מריצים את זה אצלך (חשוב!)
אני לא יכול להריץ `npm install` בסביבה שבה אני עובד (אין לי גישת אינטרנט
כאן), אז חלק מהקוד לא נבדק בפועל מול הגרסה המדויקת של הספריות. תריץ אצלך
ותגיד לי אם יש שגיאות - נתקן מיד.

1. ודא שמותקן Node.js (גרסה 18 ומעלה) במחשב שלך.
2. בתיקיית הפרויקט:
   ```bash
   npm install
   npm run dev
   ```
3. פתח בדפדפן: http://localhost:3000
4. אמור להופיע לוח חודשי לועזי ומתחתיו לוח חודשי עברי, לחודש הנוכחי.

אם יש שגיאה - תעתיק לי אותה בדיוק כמו שהיא, ונתקן ביחד.

## מבנה הפרויקט
```
app/                    עמודי Next.js (App Router)
  layout.js             שלד HTML כללי, RTL, פונט
  page.js               דף הבית - תצוגה מקדימה של הלוח
  globals.css           עיצוב גלובלי + כללי הדפסה
components/
  CalendarMonthView.jsx  קומפוננטת הליבה שמציגה חודש כטבלה
lib/
  hebcal.js              כל החישובים: תאריכים, חגים, זמני הלכה
  supabaseClient.js       חיבור ל-Supabase (ייכנס לשימוש בפאזה 2)
supabase/
  schema.sql              כל מבנה בסיס הנתונים המתוכנן (להרצה בפאזה 2)
.env.example              רשימת משתני הסביבה הדרושים (להעתיק ל-.env.local)
```

## מה עדיין חסר (ולמה זה מכוון בכוונה)
- **התחברות משתמשים** (Supabase Auth) - פאזה 2
- **שמירת הגדרות לוח + אירועים אישיים** בבסיס הנתונים - פאזה 2
- **חוקי חזרה של אירועים** (עברי/לועזי, יומי/שבועי/חודשי/שנתי) - פאזה 2
- **זמני הלכה בפועל בתא היום** - הפונקציות כבר קיימות ב-`lib/hebcal.js`
  (`getZmanimForDate`), רק צריך לחבר אותן לממשק ולהגדרות המשתמש - פאזה 3
- **בחירת עיצוב מתוך רשימה** (כרגע יש רק צבעים דינמיים, בלי "ערכות עיצוב" מוכנות) - פאזה 3
- **העלאת תמונות** לאירועים ולדף הבית האישי - פאזה 4
- **דף תשלום + הגבלת הורדה** למי שלא שילם - פאזה 5
- **תצוגה שנתית/שבועית**, בנוסף לחודשית - פאזה 3
- **ייצוא ל-PDF להדפסה** - פאזה 5

## מפת הדרכים המלאה (מוצע)
1. **✅ פאזה 1 (כאן):** מנוע הלוח עצמו - עברי/לועזי, חגים, שכבת Hebcal
2. **פאזה 2:** התחברות משתמשים + שמירת לוחות ואירועים אישיים ב-Supabase
3. **פאזה 3:** זמני הלכה + סדרי לימוד + ערכות עיצוב + תצוגה שנתית/שבועית
4. **פאזה 4:** יארצייטים של צדיקים (מרשימה שתעלה) + העלאת תמונות
5. **פאזה 5:** דף תשלום (Grow) + הגבלת משתמש חינמי + ייצוא PDF להדפסה
6. **פאזה 6:** ליטוש ממשק + נגישות למשתמשים שלא טכניים + פריסה (Deploy) סופית

בכל פאזה נמשיך לבנות קוד אמיתי, לא רק לתכנן. אחרי שתבדוק שהשלב הזה עובד
אצלך, נעבור לפאזה 2.
