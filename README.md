# MyLuach

מחולל לוח שנה עברי־לועזי להדפסה: תמונות, אירועים משפחתיים, זמני היום לפי שיטות, אירועים בדברי ימי ישראל ולימוד יומי.

## מבנה

| קובץ | מה יש בו |
|---|---|
| `index.html` | דף הבית: הסבר, מסלולים ושאלות |
| `app.html` | בונה הלוח |
| `assets/app.js` | כל הלוגיקה של בונה הלוח |
| `assets/app.css` | העיצוב של בונה הלוח |
| `assets/plans.js` | הגדרת המסלולים והמגבלות. מקור אחד לדף הבית ולבונה |
| `data-src/yz-data.js` | מאגר האירועים בדברי ימי ישראל (המקור לעריכה; לא עולה לאתר) |
| `assets/yz.js` | המאגר המוצפן שעולה לאתר. נבנה מחדש ב־`python3 tools/build_yz.py` |
| `tools/artifact_page.py` | הכנת עותק של דף הבית לתצוגה מקדימה |

האתר סטטי ואין בו שלב בנייה. אפשר לפתוח את `index.html` ישירות בדפדפן, או להעלות לכל אחסון סטטי (Vercel, Netlify, Cloudflare Pages).

## שלבים

1. **אתר חדש, דף בית, מסלולים ומגבלות** (נעשה). המסלול נשמר בינתיים בדפדפן לצורך בדיקה.
2. חשבונות משתמש ושמירת הלוחות בשרת (Supabase).
3. יצירת PDF בשרת וספירת הורדות.
4. סליקה ועלייה לאוויר בדומיין.
